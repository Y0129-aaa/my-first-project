## 📋 使用说明

### 首次访问提示

当用户首次访问 localtunnel 链接时，会看到一个确认页面：

1. 打开链接：https://upset-carrots-pump.loca.lt
2. 点击 **"Click to Continue"** 按钮
3. 即可进入 AI 学习工作台

### 买家视角演示

**演示路径：**
1. 访问首页 → 自动跳转到 Dashboard
2. 点击左侧菜单 **"买家视角演示"**（或访问 `/demo`）
3. 展示买家如何浏览和购买笔记

**演示要点：**
- 📱 笔记浏览体验
- 💬 与 AI 客服对话
- 🛒 下单流程
- 📄 查看已购笔记

### 卖家视角演示

**演示路径：**
1. **Dashboard 控制台** (`/dashboard`)
   - 查看今日数据概览
   - 核心指标展示
   - 转化漏斗分析
   - 收益趋势图表

2. **笔记处理** (`/notes`)
   - 上传笔记图片
   - 输入笔记内容
   - AI 自动排版
   - 生成推广推文

3. **笔记库** (`/library`)
   - 查看所有笔记
   - 管理和编辑
   - 分类和标签

4. **推文工厂** (`/posts`)
   - 自动生成推广文案
   - 多平台适配
   - 一键发布

5. **AI 客服工作台** (`/service`) ⭐ 核心功能
   - 实时会话列表
   - AI 自动回复
   - 人工接管功能
   - 接单通知

6. **知识图谱** (`/graph`)
   - 可视化知识网络
   - 笔记关联展示

## 🔧 技术说明

### 使用的技术
- **Next.js 15.1.0** - React 框架
- **React 19.0.0** - 最新版本
- **Framer Motion 11.15.0** - 动画库
- **Tailwind CSS 3.4.1** - 样式系统
- **LocalTunnel** - 内网穿透工具

### 动画特效
- ✅ 100+ 处交互动画
- ✅ 流畅的页面过渡
- ✅ 丰富的微交互
- ✅ 弹簧物理效果

## ⚠️ 注意事项

### LocalTunnel 限制
- 🔸 链接在本地服务器关闭后失效
- 🔸 首次访问需要点击确认按钮
- 🔸 适合临时演示，不适合长期使用

### 长期使用建议
如果需要永久链接，建议部署到：
- **Vercel**（推荐）- Next.js 官方平台
- **Netlify** - 免费额度充足
- **阿里云/腾讯云** - 国内访问更快

## 🚀 快速开始

### 本地运行
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:3000
```

### 生成二维码
```bash
node generate-qrcode.js
```

## 📞 支持

如有问题，请检查：
1. 开发服务器是否运行（`npm run dev`）
2. LocalTunnel 是否运行（后台任务）
3. 网络连接是否正常
