## 🎨 设计理念

### "人味"设计
- **温暖配色** - 避免冷冰冰的科技感
- **友好图标** - 使用表情符号增加亲和力
- **自然动画** - 流畅不突兀的过渡
- **关怀文案** - "欢迎"、"享受"等温暖词汇

### 动态背景
- **流动渐变** - 15秒循环的色彩流动
- **浮动元素** - 随机运动的装饰球
- **玻璃态** - 现代感的毛玻璃效果
- **光晕效果** - 呼吸式的脉冲光晕

### 交互设计
- **即时反馈** - 每个操作都有动画响应
- **自然过渡** - 页面切换流畅自然
- **微交互** - 小细节提升体验
- **一致性** - 统一的交互模式

## 📊 技术实现

### 核心技术
- **Next.js 15.1.0** - React 框架
- **React 19.0.0** - UI 库
- **Framer Motion 11.15.0** - 动画库
- **Tailwind CSS 3.4.1** - 样式系统

### 动画技术
- **CSS Animations** - 背景流动、呼吸效果
- **Framer Motion** - 组件动画、交互效果
- **SVG 动画** - 图表、环形图
- **Transform** - GPU 加速的位移动画

### 性能优化
- **GPU 加速** - 使用 transform 和 opacity
- **延迟加载** - 非关键元素延迟进入
- **代码分割** - 按页面分割代码
- **静态生成** - 大部分页面预渲染

## 🔧 自定义配置

### 修改配色
编辑 `app/globals.css`：
```css
/* 修改渐变颜色 */
.animated-gradient-bg {
  background: linear-gradient(
    -45deg,
    #ee7752, /* 修改这里 */
    #e73c7e, /* 修改这里 */
    #23a6d5, /* 修改这里 */
    #23d5ab  /* 修改这里 */
  );
}
```

### 修改动画速度
```css
/* 背景流动速度 */
.animated-gradient-bg {
  animation: gradient-flow 15s ease infinite; /* 改数字 */
}

/* 浮动元素速度 */
transition={{
  duration: Math.random() * 10 + 15, /* 改数字 */
}}
```

### 修改二维码链接
编辑 `generate-qrcode.js`：
```javascript
const baseUrl = '你的链接';
const buyerUrl = `${baseUrl}/buyer`;
```
