## 🎯 性能优化

1. **CSS 动画优先** - 使用 `transform` 和 `opacity` 触发 GPU 加速
2. **Framer Motion** - 使用 `will-change` 和 `transform` 优化渲染
3. **延迟加载** - 非关键元素延迟进入，避免页面加载卡顿
4. **减少重绘** - 使用 `transform` 而非 `top/left` 进行位移动画

## 🎨 动画时序设计

### 进入动画时序
```
页面加载 → 0ms
侧边栏 → 0ms
Logo → 200ms
菜单项 → 300ms + i*50ms
主内容区 → 200-400ms
卡片/元素 → 300ms + i*100ms
```

### 交互反馈时序
```
悬浮效果 → 200ms
点击反馈 → 100ms
弹簧动画 → 300ms (stiffness: 300)
```

### 循环动画时序
```
呼吸动画 → 2-3秒
脉冲效果 → 1.5-2.5秒
浮动动画 → 2-3秒
徽章脉冲 → 1.5-2秒
```

## 🚀 使用方法

### 使用动画组件
```tsx
import { motion } from "framer-motion";

// 渐入上浮
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.4 }}
>
  内容
</motion.div>

// 交错动画容器
<motion.div
  variants={staggerContainerVariant}
  initial="hidden"
  animate="visible"
>
  {items.map((item, i) => (
    <motion.div key={i} variants={fadeInUpVariant}>
      {item}
    </motion.div>
  ))}
</motion.div>
```

### 使用 CSS 动画类
```tsx
// 卡片悬浮效果
<div className="card-hover">内容</div>

// 按钮交互效果
<button className="btn-interactive">点击</button>

// 呼吸动画
<div className="animate-breathe">呼吸</div>

// 浮动动画
<div className="animate-float">浮动</div>
```

## 📝 自定义动画

### 调整动画时长
```tsx
transition={{ duration: 0.5 }} // 改为0.5秒
```

### 调整动画延迟
```tsx
transition={{ delay: 0.2 }} // 延迟0.2秒
```

### 调整弹簧效果
```tsx
transition={{ 
  type: "spring", 
  stiffness: 200, // 刚度（越大越快）
  damping: 20 // 阻尼（越大越稳定）
}}
```

### 创建自定义动画
```tsx
<motion.div
  animate={{
    scale: [1, 1.1, 1],
    rotate: [0, 10, 0],
  }}
  transition={{
    duration: 2,
    repeat: Infinity,
    ease: "easeInOut",
  }}
>
  自定义动画
</motion.div>
```
